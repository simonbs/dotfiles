# Repository instructions

## Keep the README current

- Review `README.md` whenever you change configuration, scripts, dependencies, or Git hooks.
- Update the README in the same commit when a change affects setup, Stow targets, commands, shortcuts, or how a tool works.
- Remove documentation for tools and settings we remove. Describe only the current setup, without migration notes or references to old tools.
- Keep it brief. Use plain English that is easy for non-native speakers to read. Avoid AI jargon, repetition, and unnecessary implementation details.
- Check documented commands and paths against the actual files before finishing. Test setup commands in a temporary folder when useful.
- If a change needs no README update, still check that the existing instructions remain correct.
